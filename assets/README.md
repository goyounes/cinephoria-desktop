# App Icons for Cinephoria Desktop

## Current Setup
- `icon.ico` - Windows app icon (copied from favicon.ico)
- `icon.png` - Linux app icon (same as favicon)  
- `icon.icns` - macOS app icon (placeholder, needs proper conversion)

## Icon Requirements
- **Windows (.ico)**: Multiple sizes (16x16, 32x32, 48x48, 256x256)
- **macOS (.icns)**: Multiple sizes (16x16 to 1024x1024)
- **Linux (.png)**: Usually 512x512 or 1024x1024
